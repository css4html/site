Variables and types

Use let and const with type annotations, inference and the number | string | boolean union.

A variable gives a value a name. Use const when you will not reassign it and let when it changes.

Type Example
number let idade: number = 19
string const nome: string = 'Ana'
boolean const estuda = true

You don’t need to annotate everything. In const estuda = true, TypeScript infers boolean. After let idade: number, assigning idade = '20' is a type error. At runtime, typeof still reports the actual type.

number | string | boolean is a union: the value may be any of those types.

LOGIC TS TIP — Let TypeScript infer the obvious and annotate what needs to be clear.

Change the values and compare the Console lines. estuda has no annotation but still has a type.
