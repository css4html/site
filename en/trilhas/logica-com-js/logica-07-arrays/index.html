Arrays: iterate, sum and find the maximum

Use lists, indexes, accumulators and the empty-list edge case.

An array is an ordered list, such as [3, 7, 2]. Indexes start at 0, so numeros[0] is 3. numeros.length counts items; it is not the final index.

Iterate and accumulate

for (const numero of numeros) visits each value. Start a sum with let soma = 0, then use soma += numero, shorthand for soma = soma + numero.

For the maximum of a nonempty list, start with the first item and compare the rest. Starting at zero can produce a value that is not even in the list when all numbers are negative.

Empty lists

An empty array has length 0. In this lesson, return null when there is no maximum. That is different from 0, which can be a valid maximum.

LOGIC TIP — Check empty lists, one item and all-negative lists before trusting the common case.

Try it

The example starts with a nonempty list. Try negative values and check both the sum and maximum. Then try an empty list: its first item is undefined, showing why this needs a separate case.
