Operadores y expresiones

Haz cuentas, compara valores y combina condiciones booleanas tipadas con && y ||.

Una expresión produce un valor: 3 * 10 es un number y 30 >= 18 un boolean. Usa + - * /, % para el resto, ===/!== para igualdad estricta y > < >= <= para comparar.

TypeScript ayuda: 20 === '20' se marca como error, porque un number nunca es igual a un string.

&& es Y, || es O. La regla de la fiesta: al menos 18 Y (invitación O acompañante): idade >= 18 && (temConvite || acompanhado). El resultado es boolean.

TIP DE LÓGICA TS — Lee la firma como una frase: recibe números y booleanos, devuelve un boolean.

Prueba

Cambia cantidad, precio y saldo. total no tiene anotación: TypeScript infiere number.
