Objetos: alumno y notas

Describe la forma de un objeto con interface y combina objetos, arrays y funciones.

Un objeto agrupa propiedades con nombre. En TypeScript, una interface describe su forma:

interface Aluno {
  nome: string;
  notas: number[];
}

Con const aluno: Aluno, el editor sabe que aluno.nome es string y aluno.notas es number[]. Una propiedad ausente o un error como aluno.nota es un error de tipo. type Aluno = { ... } funciona de forma parecida.

const impide reasignar la variable, pero aluno.nome = 'Bia' está permitido salvo que la interface use readonly. Para el promedio, suma y divide por la cantidad; lista vacía devuelve null y cero es una nota válida.

TIP DE LÓGICA TS — Una interface describe la forma del dato una vez y protege cada uso.

Prueba

Cambia el nombre y las notas. Si quitas notas, el editor indicaría que falta una propiedad obligatoria.
