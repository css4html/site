Instalación

Instala Git en Windows, macOS o Linux y valida con git --version.

TODO i18n: Traducción completa del cuerpo pendiente. Título y descripción ya están localizados; el cuerpo sigue en portugués por ahora.

Sem o binário git no PATH, nada da trilha roda. Instale uma vez e confira.

Conferir se já existe

git --version

Se aparecer algo como git version 2.x.x, pode seguir para a configuração.

Windows

  1. Baixe o instalador em git-scm.com
  2. Aceite o editor padrão (ou escolha VS Code)
  3. Deixe a opção de adicionar ao PATH marcada
  4. Abra o Git Bash ou o PowerShell e rode git --version

macOS

xcode-select --install
# ou, com Homebrew:
brew install git

Linux (Debian/Ubuntu)

sudo apt update
sudo apt install git
git --version
DICA GIT — Prefira uma versão recente (2.30+). Comandos como `git switch` e `git restore` existem nas versões modernas e deixam o fluxo mais claro que o antigo `checkout` coringa.

Checklist

  • git --version imprime uma versão
  • Você sabe qual terminal vai usar (Bash, zsh, PowerShell, Git Bash)
