Consumir a lib em app Vite

Import ESM + tag no HTML/JSX — o ciclo completo do pacote ao app.

No app consumidor (Vite + React, Vue ou vanilla):

DICA WC — Um único `import` registra a tag. Depois disso, use `` em qualquer arquivo do app.

Vanilla / HTML

// main.ts
import '@css4html/image-gallery';
<image-gallery columns="3">
  <img src="/a.jpg" alt="A" />
</image-gallery>

React

import '@css4html/image-gallery';

export function Page() {
  return (
    <image-gallery columns="3">
      <img src="/a.jpg" alt="A" />
    </image-gallery>
  );
}

Vue

<script setup>
import '@css4html/image-gallery';
</script>
<template>
  <image-gallery columns="3">
    <img src="/a.jpg" alt="A" />
  </image-gallery>
</template>
