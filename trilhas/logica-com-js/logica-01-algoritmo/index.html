O que é um algoritmo

Transforme um problema em passos claros: entrada, processamento e saída.

Um algoritmo é uma sequência de passos para resolver um problema. Não precisa começar no computador: uma receita também tem uma ordem. Na programação, os passos precisam ser claros o bastante para outra pessoa repetir sem adivinhar.

Entrada → processamento → saída

Vamos calcular um troco, considerando que o pagamento é suficiente:

  1. Entrada: receber o valor pago e o preço.
  2. Processamento: subtrair o preço do valor pago.
  3. Saída: mostrar quanto deve voltar para a pessoa.

Mudar a ordem da subtração muda o resultado. Antes de digitar código, escreva esses três passos com suas palavras.

DICA LÓGICA — Primeiro entenda o problema. Depois transforme cada passo em código.
