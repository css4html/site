Depuração e casos de borda

Veja que erros o verificador de tipos pega, leia erros no console e corrija um laço com limite errado.

Depurar é investigar a diferença entre o comportamento esperado e o observado.

O que o verificador de tipos pega

Engano Pego pelos tipos?
somarAte('3'), texto onde se espera number Sim, antes de executar
aluno.nota em vez de aluno.notas Sim, propriedade inexistente
Retornar 'Par' quando o tipo é 'par' | 'impar' Sim
Usar < em vez de <= num laço Não: o tipo continua number

Os tipos eliminam uma família inteira de erros, mas um erro de lógica produz um valor do tipo certo com o conteúdo errado. Para esses, use entradas pequenas, console.log e testes.

Erros no Console

Um SyntaxError aparece quando o código não pode ser lido, por exemplo com uma chave faltando. Um ReferenceError ou TypeError aparece durante a execução. Neste playground, os tipos são removidos antes de rodar; a checagem completa de tipos acontece no seu editor com TypeScript.

DICA LÓGICA TS — Tipos pegam enganos de formato; testes pegam enganos de lógica. Use os dois.

Seu exercício

somarAte(limite: number): number deve somar os inteiros de 1 até o limite, inclusive. Para zero ou negativo, o intervalo está vazio e a resposta é 0.
