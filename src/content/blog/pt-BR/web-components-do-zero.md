## Os 8 artigos

1. [Por que Web Components](/blog/wc-01-por-que-web-components/) — Componentes nativos do browser, agnósticos a framework — o problema que resolvem.
2. [Custom Element + Shadow DOM](/blog/wc-02-custom-element-shadow-dom/) — class extends HTMLElement, define(), attachShadow e estilos encapsulados.

5. [Mesma galeria no Vue](/blog/wc-05-galeria-no-vue/) — Montar o Custom Element num app Vue 3 (global build via CDN).
6. [Empacotar com Vite (lib mode)](/blog/wc-06-empacotar-com-vite/) — Árvore do pacote, vite.config em library mode e entry do Custom Element.
7. [Export dual: ES module + Custom Element](/blog/wc-07-export-dual/) — Exportar a classe e registrar a tag — dois jeitos de consumir a mesma lib.
8. [Consumir a lib em app Vite](/blog/wc-08-consumir-lib-vite/) — Import ESM + tag no HTML/JSX — o ciclo completo do pacote ao app.
