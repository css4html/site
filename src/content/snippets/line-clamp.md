---
title: "Limitar texto em N linhas"
description: "Corte multilinha com -webkit-line-clamp."
tags: ["truncate","tipografia"]
language: css
code: |
    .clamp-3 {
      display: -webkit-box;
      -webkit-line-clamp: 3;
      -webkit-box-orient: vertical;
      overflow: hidden;
    }
