Um **objeto** agrupa propriedades com nome: `{ nome: 'Ana', notas: [8, 6] }`. Em TypeScript, descrevemos esse formato com uma **interface**:

```ts
interface Aluno {
  nome: string;
  notas: number[];
}
```

Com `const aluno: Aluno`, o editor sabe que `aluno.nome` é `string` e `aluno.notas` é `number[]`. Esquecer uma propriedade ou digitar `aluno.nota` vira erro de tipo. `type Aluno = { ... }` funciona de forma parecida.

## const não congela objetos

`const aluno` impede reatribuir a variável, mas `aluno.nome = 'Bia'` é permitido. Para proibir, a interface pode marcar `readonly nome: string`.

## De lista para média

Some as notas e divida pela quantidade. Lista vazia devolve `null`; nota zero é dado válido.

<aside class="tip tip-logic"><strong>DICA LÓGICA TS</strong> — Uma interface descreve o formato do dado uma vez e protege todos os usos.</aside>
