Um **laço** repete instruções enquanto uma condição permite. Em `for (let i: number = 1; i <= 5; i++)`, a primeira parte cria o contador, a segunda decide se haverá outra volta e a terceira soma 1 depois de cada volta.

A anotação `: number` no contador é opcional: `let i = 1` já é inferido como `number`. Mostramos a anotação para deixar o tipo visível.

## while

`while (condicao)` testa antes de cada volta. Na contagem regressiva, `restante--` subtrai 1. Sem atualizar o valor, a condição pode continuar verdadeira para sempre. Os tipos não impedem um laço infinito: o playground interrompe a execução após 1,5 s.

<aside class="tip tip-logic"><strong>DICA LÓGICA TS</strong> — Os tipos não fazem o laço terminar: explique o que encerra cada repetição.</aside>

## Seu exercício

Complete `fizzBuzz(numero: number): string` para inteiros positivos:

- Múltiplo de 3 **e** 5: `'FizzBuzz'`.
- Só de 3: `'Fizz'`. Só de 5: `'Buzz'`.
- Caso contrário: o número como texto, com `String(numero)`.

O retorno é `string` em todos os caminhos. Por isso usamos `String(numero)`: devolver `numero` direto seria um `number`, e o TypeScript apontaria o erro. Coloque a condição mais específica **antes** das outras. **Verificar** também testa 30.
