Uma **função** reúne instruções para uma tarefa. Em TypeScript, a **assinatura** descreve o contrato:

```ts
function dobro(numero: number): number
```

`numero: number` é o parâmetro e seu tipo; o `: number` depois dos parênteses é o **tipo de retorno**. Quem chama `dobro('6')` recebe um erro de tipo no editor, em vez de um resultado estranho.

## return não é console.log

`return` entrega o resultado e encerra a chamada. `console.log` só mostra uma mensagem. Se a função declara `: number` e esquece o `return` em algum caminho, o TypeScript avisa.

## Parâmetros opcionais

`sobrenome?: string` marca um parâmetro **opcional**: dentro da função, seu tipo é `string | undefined`, então confira se ele existe antes de usar.

<aside class="tip tip-logic"><strong>DICA LÓGICA TS</strong> — Uma assinatura tipada é a documentação que o editor confere por você.</aside>
