Uma **decisão** escolhe o próximo passo a partir de uma condição. `if (condicao) { ... } else { ... }` executa só um dos dois blocos.

Para saber se um inteiro é par, teste `numero % 2 === 0`. Isso funciona para zero e negativos. O exemplo usa a regra didática **idade ≥ 16 → pode votar**, uma simplificação para praticar condições.

## Tipos literais e uniões

Em TypeScript, um texto também pode ser um tipo: `'par'` é um **tipo literal**. Juntando literais numa união, criamos uma lista fechada de respostas válidas:

```ts
type Paridade = 'par' | 'impar';
```

Uma função com retorno `Paridade` só pode devolver `'par'` ou `'impar'`. Um erro de digitação como `'ímpar'` ou `'Par'` vira erro de tipo no editor, antes de qualquer teste.

## switch com uniões

`switch (dia)` compara o valor com cada `case`. Com `type Dia = 'sabado' | 'domingo' | 'segunda'`, o editor sugere os casos possíveis e avisa se você escrever um `case` que não existe. `break` encerra o caminho; `default` cobre o resto.

<aside class="tip tip-logic"><strong>DICA LÓGICA TS</strong> — Uma união de literais transforma respostas possíveis numa lista que o editor confere.</aside>
