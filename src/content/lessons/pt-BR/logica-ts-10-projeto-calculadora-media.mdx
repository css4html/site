Vamos montar uma **calculadora de média** que gera um boletim, com funções puras: recebem dados, devolvem uma resposta e não alteram a entrada.

## Contrato em tipos

Em TypeScript, o contrato do projeto vira código:

```ts
interface Aluno { nome: string; notas: number[] }
type Situacao = 'aprovado' | 'recuperacao' | 'sem notas';
interface Boletim { nome: string; media: number | null; situacao: Situacao }
```

| Propriedade | Regra |
| --- | --- |
| `nome` | Copiar exatamente o nome recebido |
| `media` | Soma das notas dividida pela quantidade; `null` sem notas |
| `situacao` | `'sem notas'` se a média for `null`; `'aprovado'` se ≥ 7; `'recuperacao'` caso contrário |

Como `media` é `number | null`, o TypeScript obriga você a tratar o `null` antes de comparar com 7. Como `situacao` é uma união de literais, um texto errado como `'reprovado'` é recusado pelo editor.

## Divida em partes

1. `calcularMedia(notas: readonly number[]): number | null` trata a lista vazia, soma e divide.
2. `boletim(aluno: Aluno): Boletim` usa esse retorno e decide a situação.
3. Monte um novo objeto, sem modificar o aluno.
