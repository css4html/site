Una **variable** da nombre a un valor. Usa `const` si no lo reasignas y `let` si cambia.

| Tipo | Ejemplo |
| --- | --- |
| `number` | `let idade: number = 19` |
| `string` | `const nome: string = 'Ana'` |
| `boolean` | `const estuda = true` |

No hace falta anotar todo: en `const estuda = true`, TypeScript **infiere** `boolean`. Tras `let idade: number`, asignar `idade = '20'` es un error de tipo. En ejecución, `typeof` sigue revelando el tipo real.

`number | string | boolean` es una **unión**: el valor puede ser cualquiera de esos tipos.

<aside class="tip tip-logic"><strong>TIP DE LÓGICA TS</strong> — Deja que TypeScript infiera lo obvio y anota lo que debe quedar claro.</aside>
