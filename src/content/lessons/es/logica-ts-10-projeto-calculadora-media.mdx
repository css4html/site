Construye una **calculadora de promedio** que devuelve un boletín, con funciones puras. El contrato se vuelve tipos:

```ts
interface Aluno { nome: string; notas: number[] }
type Situacao = 'aprovado' | 'recuperacao' | 'sem notas';
interface Boletim { nome: string; media: number | null; situacao: Situacao }
```

- `nome`: copia el nombre recibido.
- `media`: suma ÷ cantidad; `null` sin notas.
- `situacao`: `'sem notas'` si `media` es `null`; `'aprovado'` si ≥ 7; si no, `'recuperacao'`.

Como `media` es `number | null`, TypeScript obliga a tratar `null` antes de comparar con 7. Como `situacao` es una unión de literales, un texto incorrecto es rechazado por el editor.

<aside class="tip tip-logic"><strong>TIP DE LÓGICA TS</strong> — Escribe el contrato en tipos antes de implementar: guía cada paso.</aside>
