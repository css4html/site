Un **algoritmo** es una secuencia de pasos para resolver un problema. Esta ruta usa **TypeScript**: JavaScript con **tipos**. Los tipos no cambian lo que hace el programa; describen qué valor guarda cada nombre, para que el editor señale errores antes de ejecutar.

## Entrada → procesamiento → salida

1. **Entrada:** el importe pagado y el precio, ambos `number`.
2. **Procesamiento:** restar el precio al importe pagado.
3. **Salida:** el cambio, también `number`.

Una **anotación de tipo** va después de dos puntos: `const preco: number = 12`.

<aside class="tip tip-logic"><strong>TIP DE LÓGICA TS</strong> — Primero entiende el problema; luego da tipo a cada entrada y a la salida.</aside>
