Una **decisión** elige el siguiente paso según una condición. `numero % 2 === 0` indica si un entero es par, también con cero y negativos. El ejemplo usa una regla didáctica: **edad ≥ 16 → puede votar**.

## Tipos literales y uniones

Un texto también puede ser un tipo: `'par'` es un **tipo literal**. Una unión de literales es una lista cerrada de respuestas válidas:

```ts
type Paridade = 'par' | 'impar';
```

Una función que devuelve `Paridade` solo puede devolver `'par'` o `'impar'`; un error como `'Par'` es un error de tipo antes de cualquier prueba. Con `type Dia = 'sabado' | 'domingo' | 'segunda'`, el editor sugiere los `case` del `switch` y avisa de los imposibles.

<aside class="tip tip-logic"><strong>TIP DE LÓGICA TS</strong> — Una unión de literales convierte las respuestas posibles en una lista que el editor revisa.</aside>
