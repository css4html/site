A **variable** gives a value a meaningful name, like a label. `idade` means age in the examples.

## let or const?

- Use `const` if you will not reassign the value.
- Use `let` if the value needs to change.
- Update an existing variable with `idade = 20`, without another `let`.

`=` assigns a value; it does not compare values. Reassigning a `const` causes an error. Try it, then click **Resetar** (Reset).

| Type | Example | Meaning |
| --- | --- | --- |
| `number` | `20`, `7.5` | A number, possibly with a decimal part |
| `string` | `'Ana'`, `'20'` | Text in quotes |
| `boolean` | `true`, `false` | True or false, without quotes |

`20` and `'20'` are different. `typeof 20` gives the string `'number'`.

<aside class="tip tip-logic"><strong>LOGIC TIP</strong> — Prefer names that explain the value rather than single-letter labels.</aside>
