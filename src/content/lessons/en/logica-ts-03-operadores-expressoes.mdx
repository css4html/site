An **expression** produces a value: `3 * 10` is a `number`, `30 >= 18` is a `boolean`. Use `+ - * /`, `%` for the remainder, `===`/`!==` for strict equality and `> < >= <=` to compare.

TypeScript helps here: `20 === '20'` is flagged, because a `number` can never equal a `string`. Plain JavaScript would just return `false` silently.

`&&` means **AND**, `||` means **OR**. The party rule: at least 18 **AND** (invitation **OR** companion): `idade >= 18 && (temConvite || acompanhado)`. The result is a `boolean`, the function's return type.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — Read the signature as a sentence: takes numbers and booleans, returns a boolean.</aside>
