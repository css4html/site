**Debugging** investigates the gap between expected and observed behavior.

| Mistake | Caught by types? |
| --- | --- |
| `somarAte('3')`, text instead of `number` | Yes, before running |
| `aluno.nota` instead of `aluno.notas` | Yes |
| Returning `'Par'` for type `'par' \| 'impar'` | Yes |
| `<` instead of `<=` in a loop | **No**: still a `number` |

Types remove a whole family of bugs, but a **logic error** produces a correctly typed wrong value. Use small inputs, `console.log` and tests. In this playground types are stripped before running; full type checking happens in your TypeScript editor.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — Types catch shape mistakes; tests catch logic mistakes. Use both.</aside>
