A **decision** picks the next step from a condition. `numero % 2 === 0` tells whether an integer is even, including zero and negatives. The example uses a simplified teaching rule: **age ≥ 16 → may vote**.

## Literal and union types

A string can be a type: `'par'` (even) is a **literal type**. A union of literals is a closed list of valid answers:

```ts
type Paridade = 'par' | 'impar';
```

A function returning `Paridade` can only return `'par'` or `'impar'`; a typo such as `'Par'` becomes a type error before any test runs. With `type Dia = 'sabado' | 'domingo' | 'segunda'`, the editor suggests the `switch` cases and flags impossible ones.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — A union of literals turns possible answers into a list the editor checks.</aside>
