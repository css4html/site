Build a **grade average calculator** that produces a report. Use pure functions: receive data, return a result and leave the input unchanged. No `prompt`, `alert`, HTML interface, randomness or storage is needed.

## Project contract

Input is a student such as `{ nome: 'Ana', notas: [8, 6] }`. Assume `nome` is text and `notas` is always an array of finite numbers from **0 to 10**. Validating other formats is an optional challenge outside these checks.

`boletim(aluno)` must return an object with these three properties:

| Property | Rule |
| --- | --- |
| `nome` | Copy the received name exactly |
| `media` | Sum divided by count, or `null` with no grades |
| `situacao` | `'sem notas'` if average is `null`; `'aprovado'` if average is at least 7; otherwise `'recuperacao'` |

Use those exact Portuguese strings, without accents in `'recuperacao'`. Do not round or convert the average into text. Zero counts as a grade; no grades is **not** a zero average.

## Break it down

1. `calcularMedia(notas)` handles the empty list, sums and divides.
2. `boletim(aluno)` uses that result to select a status.
3. Return a new object without modifying the student.

The example demonstrates the helper. Output object property order does not matter to the checker; property names and values do.
