A **decision** chooses the next step based on a condition that is true or false.

## if, else and blocks

`if (condition) { ... }` runs a block when the condition is true. `else` runs the alternative block. Braces group statements, and only one of these two paths runs.

To check whether an integer is even, use `numero % 2 === 0`. A zero remainder means exact division by 2, including zero and negative even integers.

The example uses the simplified teaching rule **age 16 or older → may vote**. This is a practice condition, not a complete explanation of Brazilian election law or compulsory voting.

## switch

`switch (value)` compares a value against each `case` using strict equality. `break` exits that path; without it, execution continues into the next case. `default` handles values with no matching case. The example groups Saturday and Sunday before one `break`.

<aside class="tip tip-logic"><strong>LOGIC TIP</strong> — Test both paths and their boundary: ages 15, 16 and 17, for example.</aside>
