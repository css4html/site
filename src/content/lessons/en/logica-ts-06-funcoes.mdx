A **function** groups instructions for a task. In TypeScript, its **signature** is a contract: `function dobro(numero: number): number`. Calling `dobro('6')` becomes a type error in the editor.

`return` hands back the result; `console.log` only displays a message. If a function declares `: number` and forgets to return on some path, TypeScript warns you.

`sobrenome?: string` marks an **optional** parameter; inside the function its type is `string | undefined`.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — A typed signature is documentation the editor checks for you.</aside>
