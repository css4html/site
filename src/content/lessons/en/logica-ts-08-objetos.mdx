An **object** groups named properties. In TypeScript, an **interface** describes its shape:

```ts
interface Aluno {
  nome: string;
  notas: number[];
}
```

With `const aluno: Aluno`, the editor knows `aluno.nome` is a `string` and `aluno.notas` a `number[]`. A missing property or a typo like `aluno.nota` is a type error. `type Aluno = { ... }` works similarly.

`const` prevents reassigning the variable, but `aluno.nome = 'Bia'` is allowed unless the interface marks it `readonly`. For the average, sum and divide by the count; an empty list returns `null`, and zero is a valid grade.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — An interface describes the data shape once and protects every use.</aside>
