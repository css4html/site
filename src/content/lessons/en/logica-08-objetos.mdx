An **object** groups named properties: `{ nome: 'Ana', notas: [8, 6] }`. `nome` stores text and `notas` stores an array. Access them by name: `aluno.nome` and `aluno.notas`.

`aluno.notas.length` reads the size of the nested array. `aluno['nome']` is another way to access a property, useful when its name comes from a variable.

## const does not freeze objects

`const aluno` prevents reassigning the variable to another object, but changing `aluno.nome = 'Bia'` is allowed. Be careful: other code may refer to the same object.

Our average function will **read without changing** its input, making it easier to repeat the test.

## From a list to an average

Sum the grades and divide by their count. Handle an empty array before dividing: return `null` if there are no grades. A zero grade is valid data, not an absent value.

<aside class="tip tip-logic"><strong>LOGIC TIP</strong> — An object can contain a list, and a function can receive the entire object.</aside>
