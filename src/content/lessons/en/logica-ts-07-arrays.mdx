An **array** stores values in order. `number[]` means **a list of numbers**; `numeros[0]` is the first item and `numeros.length` the size. Inside `for (const numero of numeros)`, TypeScript knows `numero` is a `number`.

`readonly number[]` promises the function only reads the list: `numeros.push(1)` inside it is a type error. An empty list has no largest number, so the return type `number | null` makes callers handle `null`. Zero is a valid result, not absence.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — Returning number | null forces callers to think about the empty list.</aside>

## Try it

Make the values negative and check the sum and the largest. In an empty list, `numeros[0]` is `undefined`.
