An **algorithm** is a sequence of steps that solves a problem. This trail uses **TypeScript**: JavaScript with **types**. Types do not change what the program does; they describe what kind of value each name holds, so your editor can flag mistakes before running.

## Input → processing → output

1. **Input:** the amount paid and the price, both `number`.
2. **Processing:** subtract the price from the amount paid.
3. **Output:** the change, also a `number`.

A **type annotation** goes after a colon: `const preco: number = 12`.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — Understand the problem first; then type each input and the output.</aside>
