Build an **average calculator** that returns a report card, using pure functions. The contract becomes types:

```ts
interface Aluno { nome: string; notas: number[] }
type Situacao = 'aprovado' | 'recuperacao' | 'sem notas';
interface Boletim { nome: string; media: number | null; situacao: Situacao }
```

- `nome`: copy the received name.
- `media`: sum ÷ count; `null` without grades.
- `situacao`: `'sem notas'` if `media` is `null`; `'aprovado'` (passed) if ≥ 7; otherwise `'recuperacao'` (make-up).

Because `media` is `number | null`, TypeScript makes you handle `null` before comparing with 7. Because `situacao` is a literal union, a wrong string is rejected by the editor.

<aside class="tip tip-logic"><strong>LOGIC TS TIP</strong> — Write the contract as types before implementing: it guides every step.</aside>
