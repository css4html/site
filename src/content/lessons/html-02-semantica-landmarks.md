Tags semânticas comunicam o **papel** de cada região — para humanos, CSS e tecnologias assistivas.

## Landmarks comuns

| Elemento | Uso típico |
| --- | --- |
| `header` | Introdução / marca / topo |
| `nav` | Conjunto de links de navegação |
| `main` | Conteúdo principal (um por página) |
| `article` | Conteúdo autocontido |
| `section` | Bloco temático com cabeçalho |
| `aside` | Conteúdo complementar |
| `footer` | Rodapé da página ou do article |

Evite landmarks vazios só “para layout” — isso é papel do CSS.
